# Pipeline de Patrocinios 2027

Tablero para darle seguimiento a las colaboraciones de marcas de **Mentores en Línea**.

## Qué hace
- Columnas por etapa: Enviado → Respondió → Reunión → Propuesta → Cerrado / Perdido
- Añadir, editar, mover y borrar marcas (click en una tarjeta para editarla)
- Guarda los datos en el navegador (`localStorage`)
- Alerta de follow-up cuando una marca lleva 7+ días sin contacto

## Archivos
| Archivo | Qué es |
|---|---|
| `index.html` | Estructura de la página (QUÉ hay) |
| `styles.css` | Diseño (CÓMO se ve) |
| `app.js` | Datos y comportamiento (QUÉ hace) |

## Cómo usarlo
Abre `index.html` en el navegador. No hay que instalar nada.

> Nota: los datos se guardan en el navegador donde los entres. Si abres la página en otro navegador o dispositivo, empiezas en blanco.
